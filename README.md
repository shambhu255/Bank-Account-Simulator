# Bank Account Simulator

## Project Description

Bank Account Simulator is a Python-based console application developed to simulate basic banking operations.

The project demonstrates account creation, PIN-based login, balance enquiry, deposits, withdrawals, transaction history, input validation, and CSV-based data storage.

## Features

- Create Account
- Generate Account Number
- PIN-based Login
- Check Balance
- Deposit Money
- Withdraw Money
- Insufficient Balance Validation
- Transaction History
- CSV File Storage
- Input Validation
- Logout

## Technologies Used

- Python 3
- CSV
- OS Module
- Datetime Module

## Agile Methodology

The project is developed and managed using Agile methodology with a Kanban board.

### Kanban Workflow

Backlog → To Do → In Progress → Testing → Done

## How to Run

1. Install Python 3.
2. Download the repository.
3. Open the project folder.
4. Run `bank_account_simulator.py`.
5. Select the required option from the menu.

## Project Purpose

This project is developed for academic learning and demonstrates Python programming, file handling, validation, and Agile project management.

## Disclaimer

This is an educational banking simulator. It is not connected to real banks, UPI, payment gateways, or financial services.
